# create-rn Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 实现可安装、可移植的 Expo + Tamagui 三端脚手架。

**Architecture:** CLI 根目录沿用 create-app 的轻量 TypeScript 工具链，内置单包 Expo 模板。解析、模板渲染和安全目录替换独立，实际发布包包含 bundle.js 和模板。

**Tech Stack:** Node 22.13+ compatible releases、TypeScript、Clack、Execa、Rolldown、Vitest、vite-plus；生成项目采用 Expo 58、React 19、RN 0.88、RN Web、Tamagui 3、React Navigation、Zustand、Axios。

**Spec:** ../specs/2026-11-10-create-rn-design.md（用户已确认实施；在当前会话直接执行，不再重复请求流程确认）。

## Global Constraints

- 仅 Android、iOS、Web/H5，不支持小程序。
- 不修改 create-app/soulmate-app，不 commit、push、publish；publishConfig.registry 固定公司 Verdaccio。
- 内置模板使用安装入口相对路径，不能有工作区绝对路径或 file:/link:/workspace: 依赖。
- 单包 src 分层，统一 Tamagui UI 与主题，不带业务后端、密钥、品牌素材或音视频依赖。
- 无参数误用退出 2，运行失败退出 1，成功/取消退出 0；非 TTY 不等待输入。
- 生成项目独立使用；默认不安装、不启动、不预构建。

## Review Focus

- Windows 保留名、大小写和符号链接：校验拒绝危险输入，覆盖只能发生在明确子目录。
- 覆盖中途失败：旧文件必须完整保留或恢复，临时目录在安全范围内清理。
- 空目录启动与有空格路径：真实 tarball 安装后的 CLI 必须找到模板并正确提示命令。
- 元数据包含引号/换行：通过 JSON 字面量渲染 app.config，不能破坏 TS 语法。
- Git 缺失/失败：项目仍创建成功；生成过程不能遗留源码路径或模板标记。
